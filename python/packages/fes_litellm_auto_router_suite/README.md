# fes-litellm-auto-router-suite

Shared Python primitives for the litellm-auto-router-suite: package identity and the small
typed surface that the content packages (LiteLLM plugins, headroom service clients) import.
It is a uv workspace member under `python/packages/`, linted, type-checked, and tested by the
gates configured in the workspace root `pyproject.toml`; the repo-root `LICENSE` and `NOTICE`
govern this distribution.
